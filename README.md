# Centro Odontológico Yenmar

Sitio web del Centro Odontológico Yenmar: https://odontologiayenmar.com

- Información de la clínica, servicios y equipo de odontólogos.
- Solicitud de citas en línea: el paciente elige odontólogo, servicio, día y hora, y la solicitud queda **por confirmar** hasta que el odontólogo la aprueba.
- Panel privado para los odontólogos (`panel.html`), con acceso por cuenta.

Sitio estático (HTML, CSS y JavaScript) con Firebase. Los datos están protegidos por las reglas de `firestore.rules`.
